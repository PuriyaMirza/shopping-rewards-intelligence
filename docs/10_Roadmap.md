# Roadmap

## Milestone 1 — Repository and prompt MVP

- Finalize version 1.0 product documents
- Implement first system prompt
- Create modular capability prompts
- Run core acceptance scenarios
- Record failures and product decisions

Exit criterion: average benchmark score at least 4.0 with no critical failures on the core suite.

## Milestone 2 — Personal use validation

- Use the assistant on real purchases for several weeks
- Capture requests, outputs, decisions, and corrections
- Identify where public rewards data is incomplete
- Refine response density and verification language

Exit criterion: the assistant reliably saves research time and provides useful rewards information without repeated prompting.

## Milestone 3 — Tool-backed prototype

- Build explicit intent routing
- Add structured retailer and rewards schemas
- Implement source adapters
- Add automated evaluation runs
- Store retrieval timestamps and confidence

Exit criterion: modular tool-backed version outperforms the prompt-only MVP on accuracy or efficiency.

## Milestone 4 — Historical intelligence

- Store public reward snapshots
- Analyze typical rates and recent highs
- Add “is this a good rate?” support
- Define alert thresholds

Exit criterion: historical recommendations are supported by sufficient clean data.

## Milestone 5 — Product interface

Evaluate:

- Web application
- Browser extension
- Mobile-friendly experience
- Saved shopping lists
- Conditional reward alerts

## Deferred opportunities

- Capital One and additional card portals
- Additional airline malls
- Price history
- Inventory tracking
- Warranty analysis
- Sustainability criteria
- Travel reward transfers and award booking
- Automatic checkout

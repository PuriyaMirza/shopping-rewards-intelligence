# Exact-Product Optimization Pattern

## User

Where should I buy the Sony WH-1000XM6?

## Target structure

- Preserve the exact model
- List credible or authorized retailers carrying the item
- Show current price, rewards, promotions, pickup, and open-box options when verifiable
- Separate price savings from rewards
- Recommend the best overall path and the best rewards path
- End with a short portal and checkout verification checklist

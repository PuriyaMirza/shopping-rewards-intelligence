# Browse Response Pattern

## User

Show me places that sell bath towels.

## Target structure

1. One-sentence framing with any low-risk assumption.
2. Compact table organized by retailer segment.
3. Rewards columns visible immediately.
4. One-line retailer positioning notes.
5. Brief guidance on which segment to explore next.
6. Verification note for dynamic rates.

The response should not immediately choose one towel or bury rewards below a long essay.
